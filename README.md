# 🌐📝 Blog

Repositório com os arquivos-fonte, configurações e conteúdo do meu **site/blog pessoal**, publicado em:

🔗 **https://saulogil.netlify.app/**

Este projeto reúne tudo o que é utilizado para construir e publicar as páginas do site, incluindo posts, páginas, tema, arquivos públicos já gerados e configurações do ambiente.

---

## 📖 Sobre o projeto

Este repositório corresponde ao conteúdo do meu site pessoal e blog. Aqui estão armazenados os arquivos responsáveis pela estrutura do site, pelo conteúdo publicado e pela configuração de implantação.

De forma geral, o projeto parece seguir um fluxo típico de construção de site estático com **R**, **R Markdown / blogdown**, **Hugo** e publicação via **Netlify**.

---

## 🎯 Objetivo do repositório

Este repositório foi criado para:

- centralizar os arquivos do meu blog/site pessoal;
- organizar posts, páginas e recursos visuais;
- manter a estrutura do tema e da publicação do site;
- permitir atualização e reprodutibilidade do conteúdo publicado;
- servir como base para futuras edições do website.

## 📁 Descrição dos principais diretórios e arquivos

### `content/`
Contém o conteúdo principal do site, como páginas e posts.

### `data/ads/`
Diretório de dados auxiliares usados no site.

### `layouts/shortcodes/blogdown/`
Inclui componentes e atalhos personalizados utilizados pelo **blogdown**.

### `public/`
Contém a versão já renderizada do site, pronta para publicação.

### `resources/_gen/assets/scss/`
Armazena recursos gerados durante o processo de build, especialmente relacionados a estilos.

### `themes/hugo-apero/`
Tema utilizado pelo site. O repositório indica uso do tema **hugo-apero**.

### `.Rprofile`
Arquivo de configuração do ambiente R.

### `Blog.Rproj`
Arquivo de projeto do **RStudio**.

### `README.Rmd`
Versão editável do README em **R Markdown**.

### `config.toml`
Arquivo principal de configuração do site em **Hugo**.

### `index.Rmd`
Arquivo da página inicial em **R Markdown**.

### `netlify.toml`
Configuração de build/deploy para publicação com **Netlify**.
